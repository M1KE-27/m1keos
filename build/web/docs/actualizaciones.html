Actualizaciones

Se piden, no se empujan.

Ponerte al día

mpm update && mpm upgrade

El repositorio oficial ya viene configurado en el sistema. Si quieres comprobarlo o añadir otro:

mpm source list
mpm source add https://m1keos.duckdns.org/mpm/

Qué se actualiza así

PaqueteQué lleva
mpmEl propio gestor de paquetes
mcoreLas herramientas m-* del sistema
mike-desktopLa barra, el Centro de Control, Hyprland
mkshellLa shell
mikeos-kernelEl kernel

Si algo sale mal

mpm rollback

En btrfs vuelve a la instantánea que se tomó justo antes de instalar: el sistema entero, no una lista de archivos.

Si el kernel nuevo no arranca

Al instalarse, el kernel anterior se guarda en la partición EFI como EFI/mikeos/vmlinuz-anterior.efi. Se elige desde el menú de arranque de la UEFI y el equipo vuelve a encender. Un kernel sin vuelta atrás es un portátil que no enciende.

Cosas que conviene saber

  • Nada se instala solo. Actualizar es una decisión tuya.
  • Un programa abierto no cambia de versión. La barra se recarga al reiniciar la sesión; el kernel, al reiniciar el equipo. Pasa en todos los sistemas.
  • Cada paquete se verifica por SHA256 contra el índice antes de instalarse.
